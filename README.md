## About

OPES EDGE is an AI-powered smart community and sustainable development platform.  
It unifies six essential services into one accessible, modern web application:

- 🌾 Agriculture
- 🎓 Education
- 🏥 Healthcare
- 🤝 Community Services
- ⚡ Energy Management
- 💧 Water Management

## Technology Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML5, CSS3, Bootstrap 5, Bootstrap Icons, Vanilla JS |
| Backend | Python 3, Flask |
| Database | SQLite3 |
| Fonts | Google Fonts (Inter) |

# 💡 What is OPES EDGE?

OPES EDGE is an **AI-powered Smart Community and Sustainable Development
Platform** designed to connect multiple real-world service domains
within a unified digital ecosystem.

The platform brings together:

| 🌾 | 🎓 | 🏥 | 🤝 | ⚡ | 💧 |
|---|---|---|---|---|---|
| **Agriculture** | **Education** | **Healthcare** | **Community** | **Energy** | **Water** |

Instead of building isolated applications for individual problems,
OPES EDGE follows an integrated-platform approach.
